# Ciclo do crédito

A seção de solução do site com o ciclo do crédito animado: uma operação de exemplo passa pela originação, tem as parcelas cobradas, atrasa a quarta, vai para recuperação, fecha um acordo e é quitada. O desenho está em `docs/design.md`.

É um app Vite, React e Tailwind à parte do site estático da raiz, que ainda não o usa.

```sh
pnpm install
pnpm dev        # http://localhost:3003
pnpm test
pnpm build
```
